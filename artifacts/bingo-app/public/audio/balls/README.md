# Bingo Ball Audio Files

Place one MP3 file per ball number in this folder.

## Naming convention

`{COLUMN}{NUMBER}.mp3`

Examples:
- `B1.mp3`  → "B 1"
- `B15.mp3` → "B 15"
- `I16.mp3` → "I 16"
- `I30.mp3` → "I 30"
- `N31.mp3` → "N 31"
- `N42.mp3` → "N 42"
- `G46.mp3` → "G 46"
- `G60.mp3` → "G 60"
- `O61.mp3` → "O 61"
- `O75.mp3` → "O 75"
